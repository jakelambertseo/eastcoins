Shareable MultiView links added

Added a Share action to MultiView that packages the current two-, three-, or four-panel layout, visible event/manual-URL sources, and panel split sizes into a single EastCoin link. Opening a shared link recreates that MultiView on another browser without requiring an account or backend room, while personal interface choices such as Twitch chat, navigation mode, focus state, and hidden controls remain local to each viewer.
