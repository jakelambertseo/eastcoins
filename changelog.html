📝 Changelog
EastCoin updates

Changelog

A simple timeline of the major features, games, and interface improvements added to EastCoin.

11 major update groups
July 2026

EastCoin goes live

Launched the dark burgundy-and-gold site shell with the Live Player, user-entered stream URLs, and embedded Twitch chat.

July 2026

Shareable rooms and Favorites

Added watch links, Share Room, quick links, and a Favorites page for loading approved sites directly into the player.

July 2026

Games hub and resizable chat

Added the Games library, embedded game player, external game cards, and a draggable divider for changing Twitch chat width.

Late July 2026

Sidebar and community upgrades

Added mobile navigation, remembered sidebar state, the NFL kickoff countdown, and the official “zwades is blue” card.

Late July 2026

EastCoin Bonk launches

Introduced 45-second rounds, the EastCoin target roster, combo scoring, sound effects, local best scores, and shareable results.

August 2026

Bonk jackpots and House Traps

Added the spoken countdown, Waldo and Blue Zwades jackpot events, mixed picture and classic traps, and 3–8 temporary traps per round.

August 2026

Aim Trainer and Button Masher

Added two new EastCoin arcade games with full wrapper pages, Twitch chat, personal bests, and branded Discord score cards.

August 2026

Interface cleanup and Changelog

Compacted the navigation, added collapsible player controls, fixed nested game loading, embedded games directly, and added this update timeline.

August 2026

Sitewide UX overhaul

Added Theater Mode, collapsible Twitch chat with a mobile drawer, embed loading and recovery screens, continue-watching and recent game history, a reorganized Games library, and a shared Settings panel for sound, motion, navigation, chat, and player controls. Theater Mode was then corrected to use a true full-viewport player, and the new interface was refined to match EastCoin's ultra-dark burgundy-and-gold styling.

August 2026

Streamed server browser launched

Published the Streamed event browser as the main Live Player. Live events now open automatically, each event loads every available source and server, and users can switch between streams without reloading EastCoin. The selector includes HD/SD and language labels, recommended-stream handling, server-aware Share Room links, and a direct return to the complete live-event list. Event rows and selected-stream controls now display team badges from the Streamed Images API, with event-poster and initials fallbacks when badges are not available. Shared Room links now carry the event source map, restore the complete server selector without a startup race, reopen player controls automatically, and retain compatibility with older shared links.

August 2026 Latest

Zwades agreement gate launched

Added the mandatory one-time “Zwades is Blue” confirmation across every EastCoin page, including direct game and scorecard URLs. The full-screen gate requires a manual I Agree click, blocks keyboard and pointer access until accepted, and remembers agreement through a refreshed 400-day cookie plus browser storage. The former test URL now opens a fresh agreement preview.
