July 2026

Shareable rooms and Favorites

Added watch links, Share Room, quick links, and a Favorites page for loading approved sites directly into the player.

July 2026

Games hub and resizable chat

Added the Games library, embedded game player, external game cards, and a draggable divider for changing Twitch chat width.

Late July 2026

Sidebar and community upgrades

Added mobile navigation, remembered sidebar state, the NFL kickoff countdown, and the official “zwades is blue” card.

EastCoin Bonk launches

Introduced 45-second rounds, the EastCoin target roster, combo scoring, sound effects, local best scores, and shareable results.

Bonk jackpots and House Traps

Added the spoken countdown, Waldo and Blue Zwades jackpot events, mixed picture and classic traps, and 3–8 temporary traps per round.

Aim Trainer and Button Masher

Added two new EastCoin arcade games with full wrapper pages, Twitch chat, personal bests, and branded Discord score cards.

August 2026

Interface cleanup and Changelog

Compacted the navigation, added collapsible player controls, fixed nested game loading, embedded games directly, and added this update timeline.

August 2026

Sitewide UX overhaul

Added Theater Mode, collapsible Twitch chat with a mobile drawer, embed loading and recovery screens, continue-watching and recent game history, a reorganized Games library, and a shared Settings panel for sound, motion, navigation, chat, and player controls. Theater Mode was then corrected to use a true full-viewport player, and the new interface was refined to match EastCoin's ultra-dark burgundy-and-gold styling.

August 2026

Streamed server browser launched

Published the Streamed event browser as the main Live Player. Live events now open automatically, each event loads every available source and server, and users can switch between streams without reloading EastCoin. The selector includes HD/SD and language labels, recommended-stream handling, server-aware Share Room links, and a direct return to the complete live-event list. Event rows and selected-stream controls now display team badges from the Streamed Images API, with event-poster and initials fallbacks when badges are not available. Shared Room links now carry the event source map, restore the complete server selector without a startup race, reopen player controls automatically, and retain compatibility with older shared links.

August 2026

Zwades agreement gate launched

Added the mandatory one-time “Zwades is Blue” confirmation across every EastCoin page, including direct game and scorecard URLs. The full-screen gate requires a manual I Agree click, blocks keyboard and pointer access until accepted, and remembers agreement through a refreshed 400-day cookie plus browser storage. The former test URL now opens a fresh agreement preview, and the agreement popup now includes the Zwades-blue visual for a little extra proof.

August 2026

Event discovery dashboard refined

Fixed empty discovery sections by allowing Live, Today, and Sports listings to load independently, added more resilient event-time handling, and made Favorite Teams useful before the first team is selected. Event cards now use a wider, denser matchup layout, the Events page has more room, and all visible descriptions focus on what visitors can browse and watch. The provider-friendly cache and no-auto-refresh approach remain in place.

August 2026

Starting Soon grid corrected

Expanded Starting Soon across the event directory and restored its intended two-column desktop layout, so more upcoming matchups are visible without creating an unnecessarily long page. Smaller screens continue to use a single readable column.

August 2026

Player and sidebar controls consolidated

Moved Theater, chat, and Settings controls to the center of the player, removed Player Help and the extra Open Source and Change URL controls, reduced the NFL countdown footprint, and grouped the three EastCoin games inside a collapsible Games menu to free more navigation space.

August 2026

Server picker moved beside the video

Replaced the large server overlay with a vertical right-side drawer so the video and play controls remain visible while choosing a source. The drawer has its own scroll area, presents each stream in a compact vertical list, and becomes a smaller bottom sheet on narrow screens.

August 2026

Share Room links shortened

Share Room now copies a compact event-based EastCoin URL containing only the event ID and selected server details. The link still opens the event directly in the player, while older long room links remain supported.

August 2026

View all streams navigation repaired

Fixed the server-drawer return button so it closes the active player, clears the event URL, and brings visitors back to the complete event directory. The button no longer depends on the removed Change URL control.

August 2026

Server selector changed to manual opening

Events now load with the video fully visible and the server drawer closed. Visitors can open it from the renamed Server Selector button, while a prominent red Close Server List button makes returning to the video clear.

August 2026

Shared event rooms open with more player space

Event links now begin with the left navigation hidden so shared rooms put the video first. A brighter red navigation button remains visible for anyone who wants to reopen the EastCoin menu.

August 2026

Watch rooms and event discovery upgraded

Added automatic next-server recovery for embeds that fail to load, a clearer event-room header, keyboard controls, event-based Continue Watching, a personalized For You section for favorite teams, and compact Live, Today, and Tomorrow browsing. Tomorrow is loaded only when selected.

August 2026

Event artwork added to player loading

The embedded-player loading screen now presents the selected event poster, team badges, matchup identity, and server details while the video connects. Combat sports and events without team data fall back to their poster or a clean generic loading state.

August 2026

Watch-night reliability and personalization added

Added stream-working feedback, player connection status, Recently Watched, a compact Your Night timeline, browser-saved server preferences, a quick Game Break drawer, and a public Status page linked below Changelog. Status checks reuse EastCoin’s cache and never poll automatically.

August 2026

Inline game breaks added to the player

Added Hide Nav and Play a Game to the centered player controls. Bonk, Aim Trainer, and Button Smasher now open inside a temporary overlay over the video, allowing visitors to play during ads or halftime and return to the event instantly without leaving or reloading the stream.

August 2026

Inline game startup loading repaired

August 2026

Player controls and inline games compacted

Reduced the size of the event-room and bottom player controls, added horizontal overflow as a fallback, expanded the same-page game overlay, and introduced compact embedded layouts for Bonk, Aim Trainer, and Button Smasher so their full play areas fit more reliably on smaller screens.

August 2026

Event-room controls simplified

August 2026

Collapsed player controls repaired

Fixed the hidden-controls state so connection badges and other actions no longer push the Show controls button underneath the player. The compact button now remains fully visible, clickable, and above the video and server drawer layers.

August 2026

Admin-controlled Halftime Jams test added

Added a private synchronization lab for testing admin-triggered YouTube halftime popups. Separate admin and viewer tabs support scheduled starts, late joining, pause, resume, resync, drift correction, autoplay handling, and ending the jam before a real multi-user WebSocket backend is connected.

August 2026

Halftime Jams floating-window test expanded

Moved the synchronized YouTube test into a compact draggable mini-player beside a mock Twitch chat, keeping the sports video visible. The admin tab now also includes a Twitch-command simulator for testing start, pause, resume, resync, and end commands before a real authenticated bot is added.

August 2026

Twitch-triggered three-video halftime test added

Replaced the manual halftime start controls with a real Twitch EventSub chat listener. Authorized users can launch, pause, resume, skip, resync, or end a synchronized three-video YouTube sequence through chat commands, while a muted controller advances the playlist automatically.

Live, Today, Tomorrow, search, sport filters, Continue Watching, and a single event grid remain, while Recently Watched, Your Night, Popular Live, Favorite Teams, Starting Soon, manual Refresh, duplicate event-page buttons, and source-count clutter were removed from the interface.

August 3, 2026

Events cache recovery added

Replaced the Events enhancement script with a new versioned filename so regular browser sessions cannot reuse the earlier looping copy. The event pages now clear only EastCoin-owned Cache Storage entries once per version, while the corrected observer keeps event cards interactive without causing continuous loading.

August 3, 2026

Events directory grouped by sport

Reworked the full Events page into a compact sports-directory layout. Live, Today, Tomorrow, search, and category filters remain at the top, while results are now separated into sport sections and ordered with live events first followed by the nearest start times. Matchup cards retain provider artwork and team logos while using the shared EastCoin black, burgundy, and gold styling.
