Use BetterTTV for both BTTV and 7TV emotes

BetterTTV includes separate provider switches for BetterTTV Emotes and 7TV Emotes. This is usually the simplest setup for an embedded Twitch chat.

BTTV
Best EastCoin option

BetterTTV setup

  1. Install BetterTTV. Use the official extension from betterttv.com.
  2. Open Twitch directly once. Visit any normal Twitch channel in the same browser and make sure BetterTTV appears in the chat settings or user menu.
  3. Open BetterTTV Settings. Use Twitch's chat settings gear or the BetterTTV entry in the Twitch user menu.
  4. Go to Emotes → Emote Providers. Turn on all of the following:
    • BetterTTV Emotes
    • 7TV Emotes
    • Animated Emotes
  5. Allow Twitch site access. In Chrome or Edge, open the extension's Details page and make sure Site access includes twitch.tv. In Firefox, confirm the extension is enabled and has Twitch permissions.
  6. Reload EastCoin one time. After that reload, moving between Live Player and Events will no longer recreate the Twitch chat iframe.
You do not need the separate 7TV extension when BetterTTV's 7TV Emotes provider is working.
7TV
Official extension

7TV setup

  1. Install the official 7TV extension. Download it through 7tv.app.
  2. Verify it on Twitch first. Open a normal Twitch channel and confirm that 7TV emotes and the 7TV controls appear there.
  3. Check browser permissions. Make sure the extension is enabled and allowed to read and change data on twitch.tv.
  4. Return to EastCoin and reload once. Test a known 7TV emote code in the embedded chat.
Still seeing plain text? The current official 7TV extension may not inject into every embedded Twitch iframe. That is an extension/embed limitation, not an EastCoin setting. Use the BetterTTV method and enable its 7TV Emotes provider instead.
Quick checks

If emotes still show as words

1

Test on Twitch

Open the same channel directly on Twitch. If the emotes fail there too, the issue is with the extension or its settings.

2

Use one provider

Temporarily disable the official 7TV extension and let BetterTTV provide both BTTV and 7TV emotes to rule out conflicts.

3

Check blockers

Temporarily test with privacy or ad-blocking extensions disabled for Twitch, BetterTTV, and 7TV domains.

4

Desktop browsers

Standard Chrome, Edge, and Firefox extensions generally do not run inside mobile browsers or the Twitch mobile app.

The reliable EastCoin recipe

BetterTTV + both provider switches + one reload
