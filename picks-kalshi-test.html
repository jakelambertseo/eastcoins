How Kalshi Pricing Maps to EastCoin

EastCoin uses the current executable ask for the side you choose — not the last trade or a synthetic consensus.

1Kalshi YES ask = the dollar cost of a $1 YES contract.
2Kalshi NO ask = the dollar cost of a $1 NO contract.
3Decimal return = 1 ÷ ask price.
4EastCoin converts that return to equivalent American odds for display.
5When you lock, EastCoin fetches the exact market fresh. If the price moved, you must review it again.
Example YES ask = $0.40 → 1 / 0.40 = 2.50x → +150 10 Test ZCoins → 25 return → 15 profit
