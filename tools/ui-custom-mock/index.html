Three things, all in one Settings window: move your screen around (unlock it and drag any piece, the way the party meter already moves), nameplates and features you choose, and two new looks on top of today's. Everything below works: try it.

1. Move things around

Press Unlock screen (or Settings → Layout). Every piece gets a gold outline and a name; drag it anywhere and it snaps to the edges and lines up with its neighbours. The eye hides a piece you don't want. Presets give a starting point.

3. Three looks

The same screen and the same pieces, in three skins. Tavern is today's. Midnight is dark glass with thin lines, for long sessions and streaming. Neon is the casino's own: magenta and gold with a glow. Click one to put it on the screen above.

How it would work

  • One layout engine for every piece. The party meter already drags and remembers itself; the same code, taught about ten pieces (HP, bag, minimap, tracker, meter, chat, quick slots, xp drops, party frames, buffs), each stored as a corner and an offset, so a layout still fits when the window changes size.
  • Saved to your character, not the browser, beside the settings the game already keeps, so it follows you to another computer. A layout is a few hundred bytes; it is saved when you press Done, not while you drag.
  • Snapping to the screen edges and to the other pieces' edges, with the teal guide lines, so things line up without effort; pieces can never be dragged off screen or under the Twitch chat.
  • Phones keep a fixed layout (there is no room to arrange), but the nameplate and feature settings and the looks work there too.
  • The looks are a skin, not a second game. Each is a set of colours, frames and fonts over the same pieces (no pixel fonts), so a new window never has to be built three times. Tavern stays the default.
  • Features off means off: turning off damage numbers, bubbles or weather also skips drawing them, so a slower computer gets faster. Nothing here costs the server anything.
