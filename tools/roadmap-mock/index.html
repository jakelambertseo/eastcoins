Building
How it would work
  • Written like the Weekly issue. A ROADMAP list in eastscape-wiki.js: each card has a title, a line, a picture key, a lane (now / next / later / rumour), a status and a wiki link. Moving a card is editing one line.
  • Pictures are the game's own art (the same keys the Weekly issue uses), and each rumour gets a blurred map and a black silhouette, so it teases without showing the map.
  • "Want this" votes would be one small server count: one heart per player per card, counted like the weekly tally, written once a minute. Optional: the page works without it.
  • The toast rides the message the page already gets on login, so nothing polls.
  • Ideas from players could go straight into the existing bug and idea inbox (the bug button's Inbox), so there's nothing new to read.
  • Kept honest: no dates until something is in testing, and the rumours never name a map.
