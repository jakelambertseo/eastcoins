EastScape UI kit draft 1 · for approval

Every window in the game, drawn from these pieces and nothing else. The surfaces, buttons and slots are the game's own pixel art (win.png, btn.png, plain.png, slot.png); what changes is that every window uses the same ones. Below the kit are two real windows as they are today and as they would be.

The kit

Three surfaces, four buttons, one row, one set of tabs, and chips for the small stuff. Five text sizes, two corner sizes. Dark glass is for things over the map only.
