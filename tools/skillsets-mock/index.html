Skilling sets

Every skill gets a set: four pieces (a hat, a coat, gloves and boots), each piece a small bonus to that one skill, and the full set a bigger one. The template is the Ditched set: a thief's kit somebody threw in the river, fished back up, so Fishing feeds Thieving. Every new set drops the same way, from a different skill or event than the one it helps, which is how the four skills the atlas found are islands (Agility, Thieving, Breeding, Tinkering) get wired into the rest. Below: what exists today, the rules, all fourteen sets, how they drop, and the master tier on the atlas's maps.

Today

Every piece of gear that helps a non-combat skill, from the rules file. Most help everything a little ("work speed", "rare drops"); very few help one skill, and only the Ditched pieces were made to be worn together.

The Ditched set has no set bonus.Its four pieces simply add up (+10% pickpocket and +12% speed for all four), and a drop picks a piece at random, so a set can take more than four drops. Both change below: every set, the Ditched one included, gets a full-set bonus, and a drop always gives a piece you don't have yet.

The rules for a set

Their own four squaresHat, coat, gloves, boots, in a Work clothes row beside your armour (settled 2026-10-01): one outfit on at a time, swapped in one click, pieces kept in a locker rather than your bag.
Small per piece, big for all fourEach piece is about +3% at its skill. The full set adds a bonus of its own that changes how the skill plays (a second ore, nothing burnt, a free pickpocket), not just "more". All four together come to about 15% faster to 99, the size of the Ditched set's 90 hours down to 76.
One skill onlyA set's bonuses apply to its own skill. They sit inside the caps the game already has, so a set plus a pet plus jewellery can't run away.
From somewhere elseEvery set drops from a different skill, an event or a boss. Nobody gets their own set by grinding their own skill: a miner wants a runner, a cook wants a breeder.
Never a duplicateA drop always gives a piece of the set you don't own yet, so four drops is a set. Found pieces go to your locker, so there are no spares to trade.
About an evening eachThe odds are set so a set takes a few hours of the source activity, as Ditched's one-in-2,500 catches does (a piece every two hours of steady fishing).

Who feeds whom

Each arrow runs from where a set drops to the skill it helps. Every skill sends one and gets one, so nobody's skill stands alone, and the four islands each get a feed in and out.

The fourteen

Ways to drop them

Eleven different ways, so getting sets doesn't feel like one grind fourteen times. Each uses something the game already does.

The master tier, on the atlas's maps

For the road past 99: a second set per skill, about twice the bonus, from the new places. Same rules, same feeds where they fit; they're why a level-110 skiller still visits a map with a boss on it.

Building it

  • The per-skill effects already exist. Sal's projects carry craft: {smithing: {dbl}}, xp: {wizardry} and gather, read by the crafting, XP and gathering code. A set is the same shape from worn items: a setFx(c) beside fxOf that adds each piece's bonus and, at four pieces, the set's own.
  • The drops are a line each in code that already runs: the catch roll (Ditched's), the course finish, the pocket table, the harvest, the pet's present, the chop, the pick, the Jackpot Thief's hit, the Star Tent, Bronny's order, a monster's drop table. "Never a duplicate" is a filter on what the roll picks.
  • The Ditched set keeps its pieces and gains its full-set bonus and the no-duplicate rule. Nobody's set gets weaker.
  • On screen: the character window (mockup 9) gets a "Sets" row (Prospector 3 of 4), the collection log a Skilling sets page, and the diaries (mockup 6) a task per set.
  • Art: four icons a set, 52 new pieces of PixelLab art for the thirteen new sets (all drawn, in art/). They don't change how you look in the world, as Ditched doesn't.
  • Performance: nothing new runs on a timer. Each bonus is read where its skill already reads a bonus.
Settled 2026-10-01: a separate Work clothes slot (see its mockup), 15% faster to 99 for a full set, and the names above. Still open: whether the master tier waits for the atlas's maps or a few come early.
