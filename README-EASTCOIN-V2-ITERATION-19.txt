EastCoin V2 — Iteration 19 — Upcoming Defaults to This Week
================================================================

BASE
----
V2 Modular Baseline — Iteration 18

CHANGE
------
Clicking the Upcoming status filter now automatically sets the date scope to:

This Week

This prevents the common empty-state confusion caused by:

Upcoming + Today

late in the day when today's games have already started.

Users can still narrow Upcoming afterward by selecting:

- Tomorrow
- Fri
- Sat
- Sun
- any other visible day tab

OTHER FILTERS
-------------
All, Live and Saved keep their existing behavior.
