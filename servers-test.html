What a mod sees on a reported server

added by Zwades · 2 reports · hidden for others

Two reports from different people hide a server automatically. Mods still see it with the count, and can restore or remove it. Removing three of someone's servers in a month pulls their Trusted flag until you give it back.

Rules of the road

  • Who: mods, and anyone you mark Trusted on the dashboard. Others don't see the button.
  • What: https:// only, host on the allowlist, one URL per server, no duplicates for the same game. The check runs before the button enables, so a bad link never gets a "submit and see".
  • Where it lives: one table, event_servers: event id, URL, who, when, reports, state. Read by the watch page and MultiView alongside the provider's own servers.
  • Limits: 5 adds per person per day. Servers expire when the event ends, so the table never grows past the day.
  • Visibility: the add and any removal show in the Activity feed and on the adder's profile ("Servers added: 12"). A 🛰️ title for the top contributor of the month would fit the existing set.
  • The frame: community servers load in the same player iframe with the same sandbox flags as provider streams; the allowlist is what keeps that safe, not the iframe.

Open questions for you

  • Trusted by hand only, or also automatically after, say, 20 settled picks and no reports?
