How it works with more than two players

  • Chambers scale with the table, so everyone's odds are identical. The cylinder gets one chamber per player, doubled up to keep at least six, and each player pulls the same number of times. Four players means eight chambers and two pulls each. Nobody's seat is worse than anybody else's, which is the thing a fixed six-chamber cylinder gets wrong the moment five people sit down.
  • There is always exactly one loser. One live round in a cylinder that gets fully emptied means the gun has to go off before the last pull. No draws, no refunds, no round where nothing happens.
  • The shape of the bet inverts as the table grows. Heads-up it is a straight coin flip for the other person's ante. At six players you are risking your whole stake to win a fifth of one, so it becomes small frequent wins and a rare painful loss — the opposite of every house game on the site, which is exactly why it is worth having.
  • The tension is real and it is mathematically honest. Each pull the odds visibly climb for whoever is next, because the empty chambers are gone. Everyone still went in at the same 1-in-N, which is what makes it fair while feeling like it is not.

Rules of the road

  • On the site only. No chat commands, no bot announcements. A lobby on the casino floor, you sit down, it runs there.
  • The outcome is settled before the first pull, from a seed whose hash is shown beforehand, same as every other game here. The clicking is playback, not a live draw.
  • Antes are taken when you sit down, not when the gun fires, so nobody can leave once the table is full.
  • A seat empties if you leave before it starts. Once it starts, closing the tab changes nothing — the result is already decided and the payout runs server-side.
  • Winnings count toward the hourly cap, which means the new table has to be added to hourlyNet() or it escapes the cap entirely.
